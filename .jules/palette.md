## 2024-05-24 - Accessibility issues in navigation components
**Learning:** This app heavily uses custom navigation components and sidebars built with raw `<button>` elements containing only icons (e.g. `lucide-react` icons). These buttons frequently lack accessible names (`aria-label`) and do not have visible keyboard focus states (e.g. missing `focus-visible:` classes), making the app difficult for screen readers and keyboard users to navigate.
**Action:** When working on navigation or header components, always ensure icon-only buttons include descriptive `aria-label`s (preferably matching the current language logic or using static Uzbek text based on the app context) and clear keyboard focus indicators (e.g., `focus-visible:ring-2 focus-visible:ring-emerald-500 focus-visible:outline-none`).
