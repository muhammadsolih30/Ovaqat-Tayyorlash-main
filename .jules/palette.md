## 2025-03-01 - Missing keyboard accessibility on interactive divs
**Learning:** In this application, standard interactive elements (like `RecipeCard` and `VideoCard`) were built using generic `<div>` tags with `onClick` handlers but completely lacked keyboard navigation support (`role="button"`, `tabIndex={0}`, and `onKeyDown` listeners) and keyboard focus styles (`focus-visible:ring`). This makes the primary content un-navigable and un-actionable for screen reader and keyboard users.
**Action:** When building or modifying custom interactive cards/elements using `<div>`, always ensure they are fully operable via keyboard by adding `tabIndex={0}`, `role="button"`, a keyboard event listener (to handle Enter and Space), and visible focus indicators like `focus-visible:ring-2 focus-visible:ring-emerald-500 focus-visible:outline-none`.
