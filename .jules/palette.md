## 2026-09-24 - Floating Action Buttons Missing Accessibility Overlaying Media
**Learning:** Found a recurring UX/accessibility pattern where icon-only action buttons (like "Save/Bookmark") floating over rich media components (like `RecipeCard` and `VideoCard`) were implemented without `aria-label`s and visible keyboard focus states. They were completely invisible to screen readers and inaccessible via keyboard navigation.
**Action:** Added `aria-label`, `aria-pressed`, and `focus-visible:ring-2` styling to these buttons. Going forward, when adding absolute positioned action elements inside interactive cards, ensure they explicitly include descriptive ARIA labels corresponding to their functional state, and test keyboard accessibility since default focus outlines might not be visibly distinct against media backgrounds.
