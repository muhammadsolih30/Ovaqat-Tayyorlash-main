## 2024-03-24 - Interactive Card Keyboard Accessibility & Nested Actions
**Learning:** In React applications where `<div>` elements act as complex clickable cards containing nested interactive elements (like icon-only buttons), keyboard accessibility is often entirely missing, breaking tab navigation and screen reader functionality. This app's `RecipeCard` component lacked keyboard bindings, ARIA labels for nested actions, and focus visibility rings despite visually functioning as a button.
**Action:** When creating or modifying clickable cards `<div>`, always provide `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler (for Enter/Space keys) to ensure parity with native buttons. Additionally, ensure all interactive inner elements (e.g., save toggles) have an explicit `aria-label` (localized to the app's language context, if necessary, or fallback strings) and visible focus rings `focus-visible:ring-2 focus-visible:ring-emerald-500 focus-visible:outline-none` so keyboard navigators have explicit feedback of where they are on the page.
