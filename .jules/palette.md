## 2025-05-18 - Hover Visibility Requires Focus Visibility
**Learning:** Found an accessibility pattern where utility classes that hide elements until hovered (`opacity-0 group-hover:opacity-100`) completely break keyboard navigation, as these interactive elements (like scroll arrows or save buttons) remain visually hidden when focused via the `Tab` key.
**Action:** When applying hover-based visibility utility classes (like `group-hover:opacity-100` alongside `opacity-0`) to interactive elements, always pair them with keyboard focus visibility classes (e.g., `focus-visible:opacity-100 focus-visible:ring-2 focus-visible:outline-none`) to ensure they remain accessible and visible to users navigating via keyboard. Additionally, ensure icon-only interactive elements receive descriptive `aria-label` attributes.
